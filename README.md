The program in `main.ts` writes that single line (154 characters) to `entry.txt` in the output directory, after checking it fits the 1–279 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
